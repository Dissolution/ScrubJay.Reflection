# `ScrubJay.Reflection`

ScrubJay reflection library, an extension upon [ScrubJay.Core](https://www.nuget.org/packages/ScrubJay.Core).

There are many different aspect to reflection and this library touches upon most of them.


## Method Decompilation

Transforming a `MethodBase` into a series of IL Instructions
